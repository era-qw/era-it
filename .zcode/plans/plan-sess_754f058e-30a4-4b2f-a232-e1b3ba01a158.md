# Сайт-портфолио Era/IT — план реализации

**Примечание:** папка проекта `991` пуста, референс-файл не приложен — ориентируюсь на письменное описание стиля из ТЗ (чёрный фон, акцент #AFDDFF, техническая сетка, координаты, тонкие рамки). Всё содержимое — из ТЗ, без выдуманных фактов. Контакты (WhatsApp/Telegram) — placeholder'ы в конфиге, как требует п. 31.

## Стек и ключевые решения
- **React 18 + TypeScript + Vite + Tailwind CSS + lucide-react** (точно по ТЗ). Tailwind v4 (CSS-first, плагин `@tailwindcss/vite`), Vite 7, Node совместим.
- **Шрифты (Google Fonts, все с кириллицей):** Manrope 800 — крупные заголовки; Inter — текст; JetBrains Mono — технические метки (координаты, индексы, статусы).
- **База для GitHub Pages:** `base: './'` — работает под любым именем репозитория без правок (это одностраничник с якорной навигацией, роутинга нет).
- **Дизайн-система:** строгие прямые углы (без скруглений), рамки `rgba(255,255,255,0.14–0.3)`, акцент #AFDDFF дозированно (метки, ховеры, primary-кнопка «чёрный текст на голубом», свечение), моноширинный слой меток (индексы секций, координаты 43.2389° N / 76.8897° E, STATUS: AVAILABLE и т.п. — декоративно, без ложных фактов).
- **Вся редактируемая информация в одном конфиге** `src/config/site.ts`: название, слоганы, цены, пакеты, FAQ, проекты, `WHATSAPP_URL`, `TELEGRAM_URL`, endpoint формы.

## Логика воронки и секции
Порядок по ТЗ: Hero (что делаешь) → Problem (зачем) → Services (что заказать) → Pricing (сколько) → Deliverables → Process (как) → Trust (почему можно доверять — только честные формулировки из ТЗ, без выдуманных цифр/отзывов) → Portfolio → FAQ → FinalCTA + форма → Footer. Кнопки пакетов («ОБСУДИТЬ START» и т.д.) скроллят к форме и предзаполняют услугу/бюджет.

**Форма:** поля и select'ы точно по ТЗ. Если в конфиге задан `FORM_ENDPOINT` — POST JSON (готово к подключению backend); пока не задан — fallback: собирает текст заявки и открывает WhatsApp с предзаполненным сообщением + кнопки «написать в Telegram».

**Анимации:** Reveal-система на IntersectionObserver (fade-up/slide/scale с stagger), SVG draw-line для схем и таймлайна, лёгкий параллакс hero-схемы, easing по ТЗ: `cubic-bezier(0.16,1,0.3,1)` для появления, `(0.76,0,0.24,1)` для ховеров. Полная поддержка `prefers-reduced-motion`.

## Проверка после сборки (п. 30 ТЗ)
`npm run build` → preview → проверка в браузере: меню, FAQ, все CTA, отправка формы (корректность wa.me-ссылки), консоль без ошибок, отсутствие горизонтального overflow на 320/375/430/768/1280/1440/1920, favicon, битые ссылки/ассеты, мобильное меню. Скриншоты ключевых секций просматриваю сам (web-деливери, visual-judge не применяется).
